Privacy

No analytics, cookies, or network calls for your notes after the app shell is loaded.

Backup

Back up regularly. Everything lives only in this browser. If you clear site data, cookies, or the browser cache, all notes are permanently deleted and cannot be recovered without a backup file.

Use the Backup sheet to save or restore your notes (optional encryption).

Backup

One JSON file with your notes and labels. Stored only where you save or share it.

Warning: clearing browser data deletes everything. Export a backup before clearing or switching devices.

Encrypted backups use AES-256-GCM with a key from PBKDF2-HMAC-SHA512 (210,000 iterations). Your password is never stored; if you lose it, the file cannot be opened.

Share or save the file wherever you keep backups. This app never holds a folder handle; the copy only exists where you put it.
